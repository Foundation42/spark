# Hello, spark 🌐

A minimal document — the smallest exercise of markdown rendering plus
one custom component. Used as the FPS canary baseline so regressions
on the rendering hot path show up clearly without competing with the
full demo's content.

Some prose to wrap and shape. Inline ::badge{label="alpha" color=blue}
to prove the inline-component substrate is wired. *Emphasis* and
**strong** for the cascade. A couple of emoji — 🌸 🐬 ☕ — exercise
the colour-emoji fallback font cascade.
